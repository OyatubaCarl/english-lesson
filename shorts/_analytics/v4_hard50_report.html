仮説の整理 — 何が「200」を作るのか

  1. 最有力 「unfamiliar語 × 連投」の悪い相互作用。Shortsアルゴは、同じ作者の連投を最初は均等に流すが、初動のCTR/維持率が低いものから順次配信を絞る。pedantic や palpable のようなサムネで意味も読めない単語は、連投状態では他のヒット候補(同じ作者の同時投稿)に視聴者を奪われる形で、最初の小さなCTRさえ拾えない。
  2. 中 新サムネのタグライン (上帯T**) はCTRに寄与しているが、「unfamiliar語の自爆」までは救えない。T03「わかったら○○」のように "挑発" が "見せつけ" より強い可能性。
  3. 中 公開時刻 (朝 vs 深夜) は単独では弱い。06-16 22:00 tranquil は 534 と健闘、一方 06-15 22:00 vivid は 205。時刻の影響は単語×サムネに大きく支配される。
  4. 補助 サムネのカテゴリ感(難易度ラベル)。GRE / 英検1級 のような "自分ごとじゃない" レベル表示は、サムネに level を埋め込んだ瞬間ターゲット外を遮断してしまっている可能性。

Studio CSV で検証したいこと

公開APIだけでは「クリックされていないのか / クリックはされたが離脱したのか」が切り分けられません。YouTube Studio → アナリティクス → 詳細モード → 期間=06-09 以降 → 動画 → CSV ダウンロードを渡してもらえば、次の判定ができます。

  • impressions: pedantic は配信されているのか、それともそもそも流されていないのか
  • impressions CTR: 新サムネ T** は本当にクリックされているか / unfamiliar語サムネのCTRは何%か
  • average view duration / average percentage viewed: pedantic を「クリックしたが3秒で離脱」なのか「最後まで見たがリーチが薄い」なのか
  • swipe away ratio: 冒頭1秒のサムネオーバーレイ(apply_intro_thumbnail)は効いているか
  • traffic source (Shorts feed vs 検索 vs サジェスト): HIGH群はShortsフィード由来か、検索流入か

次の打ち手 (この分析からの推奨)

  1. 1日1本ペースに戻す。10分以内の連投は最低2本まで。
    残りB群10本(abstruse 等 unfamiliar 揃い) を 連投で再上げするのは最悪手。
  2. unfamiliar語は単発 × 新サムネ × 挑発系タグライン (T03/T13系) で出す。サムネに「GRE / 英検1級」のような 難易度ラベルを抑え、"わかった?" 系の質問体に寄せる。
  3. familiar語と unfamiliar語を交互配信。familiar (ubiquitous, inevitable級) で間口を広げ、unfamiliar で滞在を引っ張る。
  4. T03 (「わかったら○○」) で A/B。サンプル1だが効きそうなので、次の3本で固定して検証。
  5. 06-10 の 7本はもう 削除→再上げ したほうがいい(URLは変わるが、低スコアの固定化リスクを切る)。ただし削除前にStudio CSVで「impressionsは出ているか」を確認 — 0なら救済価値あり、1万出てクリックされていないならサムネ・タイトルだけ変えて差し替えではなく、別動画として作り直す。
