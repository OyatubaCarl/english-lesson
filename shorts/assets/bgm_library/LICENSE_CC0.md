# CC0 note for generated BGM

The `NN_<slug>.mp3` files in this directory were generated locally for this
project by `generate_cc0_bgm.py`.

- No third-party audio samples, loops, or melodies are included.
- The generated tracks are intended to be used as CC0 project assets.
- Credit is optional for CC0, but `meta.json` includes a reusable credit line
  for consistency in video descriptions.
