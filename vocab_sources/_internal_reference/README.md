# Internal Reference — 配布禁止

このディレクトリ内のデータは **内部参考のみ**。Tacos Words のリポジトリ・配布物・アプリ・サイトに含めてはならない。

## 含まれるもの

- `english-club_juniorhigh/` — english-club.jp から取得した中学英単語Excelファイル(10品詞)
- `tacos_words_jhs_master_FULL.json` — 上記xlsxを統合した、例文・和訳・教科書レッスン番号(CROWN)込みのフルJSON

## なぜ隔離するか

これらのデータは三省堂「New CROWN」中学校英語教科書のレッスン本文・例文を素材としているため、二次利用すると著作権侵害になる。english-club.jp の編集著作物としての側面もある。

## クリーンな抽出物の扱い

`../tacos_words_jhs_clean.json` に **word + grade + pos のみ** を抽出済み。これは事実情報(単語の綴り・学年・品詞)のみで著作物性が低く、配布物に含めて良い。

## 削除の判断

完全クリーンスタートにしたい場合は、このディレクトリごと削除して構わない。残しているのは、後で「どの単語が中学範囲か」を再確認する手がかりとして内部参考のため。
