## 教材ルール

1. 現行Lesson 1〜45の文法・語彙テーマの順序を変えない。
2. 各課の新出文法を英文中で複数回使用する。
3. 未習文法は、固有名詞や定型挨拶を除き原則として先取りしない。
4. 短い導入を含む英文全体で、文法課約100〜150語、語彙課約110〜170語を目安にする。
5. 日本語は逐語訳ではなく、英文の意味を保ったキャラクター和訳にする。
6. 各課に「今回の目的」「ベルとの証拠」「次の行動」を明記する。
7. `bell brass` など物語上必要な専門語は「Story Words」として明示し、通常語彙は中学基本語を中心にする。
8. キャラクター和訳では口調を出してよいが、英文にない事実を追加せず、英文の人物・行動・時刻・場所・因果を省略しない。
9. Englishとキャラクター和訳は、直前の手がかり、場面の変化、人物の反応のいずれかから自然に始め、その課で行動する理由を物語の中で伝える。
10. 「これが今日の目的」などの定型的な進行説明を毎課繰り返さず、前課の「次の行動」が次課の冒頭で実際の出来事になるよう接続する。
11. 人物が知る前に、手がかりの場所や原因を断定させない。発見の直前に視覚・音・記録などの根拠を置き、Englishとキャラクター和訳で同じ「情報を知った瞬間」を保つ。
12. Englishの直接話法には、発話の直前に `(Teacher Tacos)` のように半角丸括弧で話者名を記す。手紙、Manual、壁面などに書かれた引用文には人物の話者名を付けない。
13. 物語に実在する鐘はStory Bell一つだけとする。朝の合図、修理対象、三部品とWord Lightの装着先、最終的に鳴る鐘を別名・別個体に分けない。
14. TomとTeacher Tacosを全編の探索役とする。Tomは気づき・質問・実作業を担い、Teacher Tacosは証拠の照合・整理・安全確認を担う。各課で可能な限り二人の行動を明示する。
