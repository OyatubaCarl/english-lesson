## 制作基準

- 英語の1文につき、内容を最もよく表す専用画像を1枚用意する。
- 毎回家族全員を出さず、その文に必要な人物・物だけを置く。
- 現実、回想、会話中の想像、予定を、色調や柔らかな思考イメージで区別する。
- 場所と季節に合う服装に変える。
- ケンタは年上・高身長・そばかすなし・眼鏡なしとし、トムと区別する。
- トムはそばかすと服装で識別し、必要な話ではTeacher Tacosを小さく一度だけ登場させる。
- ミオ自身の日本語は「わたし」で統一する。トム自身の台詞の「ぼく」は維持する。
- Taco Beatの単語時刻を使い、英語を語単位で赤くハイライトする。強調時も文字サイズ・横倍率・縦倍率は変えず、英文全体の位置を固定する。
- 日本語字幕を併記し、長い英文は意味の切れ目で2〜3行、長い日本語は2行に改行する。文字サイズは変えない。
- カメラは1場面につき1種類の明確な動きにする。横パンは人物から人物へ分かる量で動かし、ズーム時は中心を固定する。小さな漂い・微小パン・パンとズームの同時使用は避ける。
- 切り替えは場面の意味に合わせ、溶暗、横移動、ぼかし、円形展開などを使い分ける。

## フォルダ構成

- `Lxx/planning/lesson.json`：英文、日本語、時刻、カメラと切り替えの設計
- `Lxx/scenes/`：1文ごとの画像
- `Lxx/captions/`：英日字幕と語単位ハイライト
- `Lxx/output/`：完成動画
- `Lxx/work/camera_qa/shot_contact.jpg`：各場面の確認用一覧
- `Lxx/work/camera_qa/movement_contact.jpg`：各場面の開始・終了を並べたカメラ移動確認用一覧
- `Lxx/planning/image_prompts.jsonl`：各1文画像のImageGen指示と参照画像
- `shared/SETTING_BIBLE.md`：Mioの家・学校・村の簡易設定
- `shared/scripts/build_story_video.py`：共通の動画生成処理
- `shared/scripts/prepare_remaining_lessons.py`：L17〜L45の文・音声タイミング・画像設計生成
- `shared/scripts/validate_remaining_lessons.py`：画像・字幕・動画の一括検証
- `shared/full_middle_video_validation.json`：L1〜L45の横断検証結果
