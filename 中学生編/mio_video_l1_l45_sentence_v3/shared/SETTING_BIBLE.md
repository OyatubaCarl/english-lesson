# 中学生編 簡易ロケーション設定

目的は建築の厳密な再現ではなく、英文を一目で理解できる画像を作りながら、同じ家・学校・村に見える程度の連続性を保つこと。

## 優先順位

1. 英文の主語・動作・感情・対象が一枚で分かること。
2. 現実、回想、想像、計画の時間層が正しいこと。
3. 必要な人物だけを出し、服装を季節・場所・活動に合わせること。
4. この設定資料の建物・部屋の骨格を保つこと。
5. 家具の細部や小物は英文を伝えやすいよう調整してよい。

## Mioの家

- 山間の小さな村にある、少し古いが手入れされた木造2階建ての日本家屋。
- 外壁は温かな木と薄いクリーム色の塗り壁。屋根は濃い灰色の瓦。南側に縁側と小さな庭があり、その先に山並みが見える。
- 玄関は東側。家の中は蜂蜜色の木枠、生成りの壁、落ち着いた暖色照明で統一する。
- 豪邸、都会の高層住宅、欧米風の大邸宅にはしない。

### 1階

- 居間・食堂: 南側。低い長方形の木のテーブル、家族が座れる椅子または座布団、庭へ出る大きな窓。家族全員の場面は原則ここ。
- 台所: 食堂につながる半開放型。木の作業台、生成りのタイル、山村の野菜が似合う。Yukaの料理場面はここ。
- Hiroshiの書斎: 北側の静かな小部屋。窓、木の机、本棚、書類用の引き出し。ほかの家族を背景に置かない。
- テレビの一角: 居間の端。Kentaが一人で見る場面では、ほかの家族を見物人として置かない。
- 縁側: 南の庭に面し、季節、天気、家族の会話を見せる場面に使う。

### 2階

- Mioの部屋: 南東。山と村が見える窓のそばに勉強机、壁際に低いベッド、左側に本棚。青灰色の寝具と小さな読書灯が目印。読書・宿題・考え事の場面ではMioだけを基本とする。
- Sakiの部屋: Mioの隣。小さな机、鍵盤楽器、画材、珊瑚色の小物。遊びや音楽の場面ではSakiだけを基本とする。
- Kentaの部屋: 廊下の反対側。背の高い本棚、スポーツバッグ、紺色系の寝具。Tomの部屋のような青緑の少年部屋にはしない。
- 各個室は壁と廊下で明確に分ける。別々の行動を描くとき、背景に家族全員を並べない。

## 学校

- 山村の小規模な中学校。1学年1クラス程度として、同じ級友が複数の役割に登場しても不自然ではない。
- 教室は木の床、淡いクリーム色の壁、黒板、二人用または一人用の木の机。大きな窓から山、校庭、村の屋根が見える。
- Mio、Tom、Yuukaは中学1年の同級生。制服は紺を基調とし、Tomは青緑のベスト・ネクタイで見分ける。
- Teacher TacosやFunnics Islandのキャラクターは、Tomが登場する話の窓外、掲示物、遠景に一度程度だけ小さく入れてよい。主題を奪わせない。

## 村と周辺

- 山、川、田畑、古い商店街が徒歩圏にある小さな日本の村。
- 図書館、博物館、工芸市場、診療所、郵便局、花屋、パン屋、古本屋は同じ町の施設として、木・石・生成り色を基調にする。
- 季節変化は大きく見せてよいが、山並みと木造の町並みを共通の目印にする。

## 可変にしてよいもの

- 英文を読み取りやすくするための画角、家具の向き、小物の数。
- 季節の布類、花、食べ物、学用品。
- 想像・回想を示す光、縁取り、柔らかな吹き出し。ただし写真や額縁を定型的に使わない。

## 禁止事項

- 文に不要な家族全員を毎回背景へ置く。
- 計画や想像を、すでに起きた現実として描く。
- KentaをTomのようなそばかす・青緑ベスト・同年齢の外見にする。
- Mio自身の日本語を「ぼく」にする。
- 祖母を示すためだけに遺影のような額入り写真を置く。
- 画像内に字幕、説明文、ロゴ、透かし、読める文字を生成する。
