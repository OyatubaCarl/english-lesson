## 1. 人格バイブル

### 性格
- 基本ごきげんで**前向き**、生徒にはとにかく**優しい**。
- **うっかり天然**：サルサやスパイスの匂いにつられて話が逸れる／ライムを置き忘れる／ふらっとどこかへ行く。
  - ※このうっかりは **毎回やらない**。効かせどころで"時々"（3〜4投稿に1回くらい）出すと生きる。毎回だとくどい。
- ゲーム作りへの愛だけは本物。派手さより、こつこつ仕込む職人肌。

### 声のルール（確定）
- **英語は1セリフに1語程度**（多くても2語）。混ぜるのは意味のある内容語（fault / boring / meet / guess / rhythm / done / easy / difficult / clear / free …）。助詞や無意味語は混ぜない。**文脈で推測できる語**を選ぶ。グロス（注釈）は付けない＝文脈任せ。
- **タコス語は"時々"の薬味**。褒め・励ましで特に効く。使うのは下のパレット内だけ：
  - ✅ サルサ / ライム / スパイス / 火加減 / 味 / フィエスタ / キレッキレ / 黄金のバランス / 仕込む / 1品 / 🌮
  - ❌ 禁止：タコス〇個などの個数換算 / 満腹 / 満貫 / 無敵モード
- **煽らない**（「さあ！」「今すぐ！」ナシ。「では、ひとくちどうぞ」くらいの温度）。
- **主張しない・説教しない**。信条をタグラインで宣言しない。学びの考え方は、投稿ににじませる程度に留める。
- **自分を「タコス」と自称しない**。名乗るなら「ティーチャータコス」。基本は名乗らず普通に喋る。
- **「現役の先生が作ってる」等、中の人の職業・素性には一切触れない**。表に立つのはキャラだけ。

### プロフィール（確定）
> 日本語に英単語を1つ混ぜて覚える、英語の学習ゲームを作ってます。無料・広告なし。…あ、どこかでサルサのいい匂い。🌮

- 表示名：ティーチャータコス／ハンドル：既存の @teachertacosenglish を流用
- アイコン：ティーチャータコス本人（めがね・にっこり）。ヘッダーはタコスの世界＋「TACOS PARTY」等のロゴ世界観で統一。

## 5. 「他人の信頼を借りる」動き方（最重要・匿名でも効く）

自分の投稿100本より、**信頼されている実在アカウント1人の"試してみた"**が効く。

1. 英語学習・教育クラスタの中〜小アカ（フォロワー数千〜数万）を10〜20、普段から**素で交流**（返信・共感）。売り込まない。
2. 関係ができたら、上の返信テンプレで**「味見してみて」**と一度だけ軽く渡す。押し売りしない。
3. 触ってくれたら全力で感謝＆リポスト。相手の文脈に乗る。
- ※これは匿名のまま完全に成立する。顔も職業も要らない。

## 6. 運用メモ

- **リンク/QRとドメインの注意**：`teachertacos.com` は現状 学校ネットのフィルタで新規ドメイン扱いになりブロックされがち。**家庭Wi-Fi・スマホ回線では開ける**ので、SNS（家で遊ぶ層）には支障なし。校内配布用のQRポスターは、フィルタの「教育」分類申請／allowlistが通ってから。
- **メディア**：試食系は必ずクリップ（縦型9:16）を付ける。文字だけより伸びる。既存の縦型ショート（youtu.be/-ukOT8mWkIY 等）を素材に。
- **ハッシュタグ**：付けすぎない（1〜2個。#英語学習 程度）。タグより本文とキャラで勝負。
- **やらないこと**：連投（1日3本以上の量産）／同型コピペ／煽り／「バズ狙い」の飛び道具。積み上げで勝つ。
- **続ける仕組み**：週の頭に「厨房から」1本ストック、あとは返信中心。作るのが辛くなったら投稿を減らして、返信だけは続ける（関係が資産）。
