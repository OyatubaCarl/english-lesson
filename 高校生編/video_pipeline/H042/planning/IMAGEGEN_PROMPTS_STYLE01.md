# H042 ImageGen 最終プロンプト設計

共通: `historical-scene` / 16:9 / 画風01 / 古代〜中世ユーラシア / 下45%字幕余白 / 読める文字なし。

1. `silk_roads_network_master` — 起伏のあるユーラシア地形模型の上に、陸路と海路が多数の分岐として光ではなく細い物理的な糸で結ばれる。一本の道路にしない。
2. `dunhuang_caravan_master` — 7世紀頃、敦煌近郊のオアシスから二こぶラクダの小規模な隊商が出発。ソグド系商人、現地案内人、水袋、実用的な荷。
3. `goods_relay_market_master` — オアシス都市の隊商宿で、漢地の絹、イラン高原のガラス、インド系香辛料、地中海の金貨が複数商人の中継取引で渡る。
4. `desert_mountain_routes_master` — タクラマカン周縁の砂漠、天山の峠、井戸と隊商宿を一つの時系列画面でつなぐ。生存を支える人と場所も描く。
5. `buddhist_transmission_master` — インド・中央アジア系僧侶、敦煌の翻訳者、壁画工房が経典・言葉・図像を地域に合わせて伝える。
6. `islam_central_asia_master` — 8〜10世紀の中央アジア都市で、モスク、中庭の学者、商人、地域住民を描く。軍事征服だけ／商人だけに単純化しない。
7. `language_art_exchange_master` — ソグド語系の商人、中国系書記、イラン系ガラス職人、中央アジアの音楽家が市場と工房で技法を交換。文字は読めなくする。
8. `samarkand_papermaking_master` — 8〜9世紀のサマルカンドで、布ぼろの処理、紙漉き枠、圧搾、乾燥を行う多文化の職人。
9. `paper_learning_chain_master` — サマルカンドの紙工房、バグダードの写本工房、後世の欧州図書室を明確に時代分割し、紙と学びの連鎖を示す。
10. `modern_student_silkroads_master` — 現代の高校生が、絹・ガラス・香辛料・貨幣・仏教断簡・紙漉き道具を一つの資料展示で比較し、ネットワークを理解する。
11. `desert_wind_legacy_master` — 夜明けの隊商路に、人・ラクダ・車輪・紙片の痕跡が自然な風紋として重なり、文明の根を支える長い交流の余韻を残す。

実行方式: 組み込み ImageGen。生成した選定画像は `scenes/character_refs/` に保存し、`final_style01` の動画用場面へ展開する。
