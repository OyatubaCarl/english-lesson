# H043 ImageGen 最終プロンプト設計

共通: `historical-scene` / 16:9 / 画風01 / 1940〜1970年代米国 / 下45%字幕余白 / 読める文字なし。

1. `carson_writer_master` — 1962年、55歳のレイチェル・カーソンが研究資料、鳥類学資料、海洋生物のスケッチを照合して執筆。女性科学者と自然作家の両面。
2. `silent_spring_publication_master` — 1962年の出版社で、カーソンと編集者が派手でない初版見本を確認。表紙の文字は読めなくする。
3. `ddt_widespread_use_master` — 1950年代米国の綿花畑・果樹園・郊外で、当時の農業用散布が広範に行われる。用途の利点も背景に示し、悪役的に単純化しない。
4. `food_web_biomagnification_master` — 湿地で水質・魚・鳥の卵を調べるフィールドチーム。水から魚、魚を食べる鳥への蓄積を一つの実在風景で示す。
5. `silent_orchard_warning_master` — 春の早朝の果樹園と住宅地。花は咲いているが巣は空で鳥の姿がない。予言的な警告として静かに描く。
6. `public_awareness_master` — 図書館・書店の読者、手紙を整理する市民、資料を検証する科学者、取材する記者が関心の広がりを作る。
7. `industry_criticism_master` — 化学企業の記者会見と、研究資料を手元に静かに応答するカーソン。攻撃は言葉・記事・法的圧力で表す。
8. `senate_testimony_master` — 1963年の米上院小委員会。カーソンが資料とサンプルを前に証言し、議員・科学者・記者が検討。ここで禁止を決定しない。
9. `epa_1972_decision_master` — 1972年のEPA事務室で、行政官と専門家が大部の証言録を確認し、DDTの大半の使用登録取消しを決定。カーソンは登場させない。
10. `environmental_movement_master` — 1970年代の多様な市民・学生・科学者が河川調査、野鳥観測、植樹、公開討論を行う。カーソン個人の勝利にしない。
11. `modern_ecological_balance_master` — 現代の同じ男子高校生が湿地保全区で魚、水生昆虫、植物、鳥、人の生活が支え合う様子を観察。回復した鳥の飛翔で終える。

実行方式: 組み込み ImageGen。選定画像は `scenes/character_refs/` に保存し、クロップ・寄り・明度調整で50前後の `final_style01` 場面へ展開する。
