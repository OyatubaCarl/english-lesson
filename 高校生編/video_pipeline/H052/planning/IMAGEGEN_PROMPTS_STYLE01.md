# H052 ImageGen 最終プロンプト設計

共通: `pandemic and public health documentary` / 16:9 / 画風01「光彩・劇場アニメ背景」 / 精密な2D線画とセル塗り人物 / 群青の影と自然な暖色光 / 下45%字幕余白 / 読める文字・数字・ロゴなし。現在場面はH15基準の17歳男子と、低く束ねた黒髪・濃紺ジャケットの42歳前後の女性公衆衛生医で連続させる。患者の尊厳を守り、感染症を怪物化せず、医療現場を扇情的にしない。

1. `wuhan_case_report_master` — 2019年末の冬の武漢。病院の診察室と公衆衛生事務室を奥行きある一場面にし、医師が匿名化された複数の肺炎症例記録と胸部画像を静かに確認して当局へ報告する。原因はまだ不明、ウイルス粒子や研究所は描かない。
2. `cross_border_spread_master` — 数週間後、空港・鉄道・港の通常の移動と、国際公衆衛生センターで複数地域から届く匿名化情報を照合する職員。赤い感染光線は使わず、人の移動と監視の難しさを示す。
3. `who_pandemic_assessment_master` — 2020年3月のジュネーブ風のWHO緊急会見。公衆衛生専門家が世界地図と増加傾向を前に加盟国へ説明する。固有ロゴ・読める資料・政治家は出さず、pandemicという評価の重さを表情で示す。
4. `lockdowns_school_business_master` — 国や地域で異なるlockdownsを、閉じた学校門、静かな商店街、家庭のオンライン学習、在宅勤務、必要業務を続ける人々を同じ街の時間経過で描く。全世界一律の軍事封鎖にしない。
5. `regional_hospital_patients_master` — 各地域の病院入口とトリアージ。PPEを着けた医療者がpatientsを落ち着いて受け入れ、救急搬送、酸素、一般病床への動線を整理する。患者名・苦痛の接写なし。
6. `icu_health_workers_master` — 満床に近づく集中治療室で、医師・看護師・技師がPPE、手指衛生、機器確認、交代記録を使ってチームで働く。自己犠牲の英雄画ではなく、risk管理と疲労を両方示す。
7. `symptoms_variation_master` — 発熱、咳、息苦しさ、倦怠感など症状が異なる複数の人を、家庭での遠隔相談と診療所での評価として描く。診断図や治療指示の読める文字は出さない。
8. `mild_and_high_risk_master` — 軽症で自宅療養しオンライン支援を受ける若者と、基礎疾患のある高齢者を慎重に診察・観察する医療者を一つの地域医療網として描く。年齢だけで運命が決まる表現にしない。
9. `vaccine_research_master` — 既存研究を基盤に、研究者が抗原設計、細胞試験、動物試験資料、製造試験を確認する現実的な研究所。魔法の一発発見や危険な病原体の露出を避ける。
10. `clinical_trial_review_master` — 多様な成人参加者の臨床試験、匿名化されたデータ、独立審査、規制当局の専門家を連続する一場面にし、速さが安全確認の省略ではないことを示す。
11. `vaccination_rollout_master` — 2020年末から2021年初頭の接種会場と低温輸送。医療者・高齢者・各地域の住民、輸送箱、保冷庫、接種後観察を描き、複数地域で開始した一方で供給量に差があることも示す。銘柄なし。
12. `preparedness_lessons_master` — 現在の公衆衛生訓練。監視、検査、PPE備蓄、換気、病床計画、医療人材、地域連絡を無文字の実物で点検する女性公衆衛生医と男子高校生。
13. `international_cooperation_master` — 複数国の研究者・保健当局・物流担当が、安全な検体情報、遺伝子データ、医療物資、ワクチン供給を公平に共有する国際調整室。国旗対立や握手だけの抽象表現にしない。
14. `next_crisis_prepared_final_master` — 夜明けの地域保健センターで、男子高校生、女性公衆衛生医、医療者、市民が訓練結果を見直し、学校・病院・地域が次のcrisisへ備える。過去を忘れず、恐怖ではなく協力と回復力で締める。

実行方式: 組み込みImageGen。選定画像は `scenes/character_refs/` に保存し、寄り画・クロップ・明度調整で約70〜80カットへ展開する。
