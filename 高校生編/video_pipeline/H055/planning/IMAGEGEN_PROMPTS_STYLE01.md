# H055 ImageGen 最終プロンプト設計

共通: aging society and intergenerational support documentary / 16:9 / H15基準の画風01「光彩・劇場アニメ背景」 / 精密な2D線画とセル塗り人物 / 群青の影と自然な暖色光 / 下45%字幕余白 / 読める文字・数字・ロゴなし。H15基準の17歳男子高校生、72歳の灰色髪の男性、69歳の銀髪の女性、34歳の男性介護職を連続させる。

1. modern_japan_intergenerational_master — 朝の現代日本。駅と商店街で高齢者が通勤、買い物、ジョギング、孫の送りを行い、若者と同じ社会を多様に生きる。弱者の行列や数字の図解にしない。
2. population_ageing_master — 公共交通と広場を使う多世代の人々。白髪、車いす、健歩、就労中など高齢期の多様性を示し、統計グラフは描かない。
3. longevity_celebration_master — 72歳男性の節目を家族と友人が祝う暖かい家。木工作品、散歩靴、本、小さなケーキで長寿と継続する生活を祝い、病室にしない。
4. workforce_pension_master — 69歳女性と複数世代が働く地域店舗。別室で行政担当者と労働者代表が年金制度を議論する様子を背景でつなぐ。天秤、年齢対立、読める書類なし。
5. medical_budget_master — 地域診療所で予防診療とリハビリを受ける高齢者、その奥で資源配分を話し合う医療者と自治体職員。巨額請求書や高齢者への非難なし。
6. welfare_policy_master — 異なる先進地域から来た行政担当者、介護者、市民代表が丸いテーブルで持続可能な福祉を協議。国旗、国名、読める資料なし。
7. changing_family_master — 別々の住まいを行き来する三世代家族。子と孫が72歳男性を訪問し、後日はビデオ通話し、ともに自立した家で生活。別居を不幸としない。
8. living_apart_loneliness_master — 藍色の夕方、72歳男性が一人分の夕食の前で、静かな部屋と手元の電話を見つめる一瞬。哀れみや危機を過剰に演出せず、望まない孤独の感覚だけを描く。
9. community_support_master — 地域サロン、共同食堂、送迎車の乗降と玄関の見守り。高齢者も配膳や受付を担い、相互に支える。
10. volunteer_visit_master — H15基準の17歳男子高校生が72歳男性を定期訪問。お茶を飲みながら木工を教わり、高校生はスマートフォンの使い方を手伝う。対等な関係。
11. care_technology_master — 介護施設で34歳の男性介護職が、本人に説明し同意を得て移乗リフトを操作。同僚は無記名の記録端末を使い、人の手と会話が中心。
12. generations_support_master — 72歳男性が子どもに木工と算数を教え、17歳男子高校生が69歳女性のスマートフォンと買い物を手伝う。一方向の奉仕ではない。
13. mutual_respect_master — 若者、高齢者、介護者が対等に、地域のベンチと段差のない花壇を一緒に作る。互いの意見に耳を傾ける手元と表情。
14. long_lived_society_final_master — 朝日の公園と地域拠点。高齢者が働き、学び、遊び、支え、必要な人は介護を受け、子どもと若者も参加。富ではなく関係と尊厳を「豊かさ」とする静かな希望の結末。

実行方式: 組み込みImageGen。選定画像は scenes/character_refs/ に原寸のまま保存し、寄り画・クロップ・明度調整で約70カットへ展開する。
