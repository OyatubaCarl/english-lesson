# H062 ImageGen生成記録（画風01）

共通基準: H15参照画の「光彩・劇場アニメ背景」。精密な2D線画、節度あるセル塗り人物、群青の影、自然な暖色光、現実的な空気透視。歌詞・舞台・生物・政策・因果の整合性を美しさより優先。16:9、下45%字幕安全域、画像内文字なし、ロゴなし、透かしなし、分割パネルなし。

1. `watershed_to_ocean_master.png` — 現代の沿岸都市、雨水水路から河川、河口、青い海へつながる広い朝の流域。ごみは散在程度。男子高校生と女性海洋研究者が河口を観察。
2. `river_mouth_sampling_master.png` — 河口の水面に少量ずつ分散する容器片と繊維。研究者が採水器を使い、男子高校生が無文字の試料瓶を持つ。
3. `truckload_scale_master.png` — 港湾の回収・計量拠点に市政の一台のごみ回収トラック、整理された回収プラスチックのベール。海への投棄なし。比喩として量を観察する学生。
4. `north_pacific_sampling_master.png` — 広大な北太平洋、白と深青の調査船から細いプランクトンネットを引く。海面は大部分が青く、ごみ片は数点のみ。ごみ島にしない。
5. `currents_disperse_debris_master.png` — 調査船から見下ろす海流の長い筋と、広い水柱にまばらに分散する小さなボトル片・ロープ片・微細粒子。ダイナミックな波だがごみの固形島なし。
6. `weathering_microplastic_master.png` — 澄んだ海水の中、太陽光と波によって傷んだ青いプラスチック片の縁が微細な破片になるマクロ観察。魔法的な発光なし。
7. `plankton_foodweb_master.png` — 海中のプランクトンと小魚、微細粒子の現実的マクロ。プランクトンネットが画面奥にあり、生態と研究を同じ水中で表現。
8. `seafood_research_uncertainty_master.png` — 沿岸研究所。同じ女性研究者が魚・貝の試料と濾過紙を顥微鏡で分析。数値や結論は読めない点と線だけ。不確実性と継続研究を静かに示す。
9. `seabird_rescue_master.png` — 沙浜の海鳥保護・調査。専門家が元気な海鳥を優しく診察し、その横に回収したプラスチック袋と網片を記録。血・死体・苦痛表現なし。
10. `coral_multiple_threats_master.png` — サンゴ礁の環境調査。ダイバーが水温センサーと水質試料を扱い、一部の白化、絡んだ細い漁網、陸由来の濁りを過度に誇張せず併置。
11. `government_reduction_policy_master.png` — 現代の小売店。無文字の繰り返し使える袋と量り売り容器、使い捨て袋を渡さないレジ。店員と男子高校生が自然に選択。ポスターや読める値札なし。
12. `reuse_recycling_industry_master.png` — 清潔な容器設計・素材選別拠点。再使用容器の設計、使用済みプラスチックの光学選別、洗浄、ペレット化を奥行きある一つの工程内で描く。無限ループ記号なし。
13. `biodegradable_seawater_test_master.png` — 海洋素材研究室。透明な海水試験槽に通常素材と代替素材の小片。同じ女性研究者が時間経過を観察。代替素材も完全に消えていない。読めるラベルなし。
14. `systems_roundtable_master.png` — 沿岸自治体の明るい協議室。行政、企業、海洋研究者、地域代表が、生産・使用・回収・再使用の抽象的な物理モデルを囲む。文字なし、握手で即解決せず共同作業中。
15. `student_reduce_reuse_recycle_master.png` — 同じ男子高校生が地域のリフィル拠点でマイボトルを満たし、再使用袋を持ち、使用済み容器を無文字の分別箱へ。小さな行動だが現実的。
16. `ocean_future_system_master.png` — 朝の沿岸。男子高校生、家族、店員、研究者が別々の役割で、リフィル、回収、調査を続ける。奥に清潔な回収車、港の選別施設、青い海。一人の行動で魔法的に全解決した図にしない。
