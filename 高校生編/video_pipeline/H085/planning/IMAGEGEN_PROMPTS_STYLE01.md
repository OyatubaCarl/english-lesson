# H085 ImageGen prompts — 画風01

共通: Use case は `illustration-story`。添付H15参照画を画風参照として使い、精密な劇場アニメ2D線画、節度あるセル塗り人物、描き込まれた背景、群青の影と自然な琥珀光に厳密に合わせる。16:9、1672×941。顔・手・教材・通学路の焦点は上55%、下45%は机・床・道・影の字幕余白。写真調、3D、油彩、分割画面、コラージュ、読める文字・数字・学校名・国際機関ロゴ・企業ロゴ・透かしなし。

人物固定: 半乾燥高地地域の12歳女子児童は細い三つ編み、黄土色セーター、深緑スカート、青い布鞄。34歳女性教師は短い編み込み髪、青緑ブラウス、焦げ茶スカート。南アジア河川平野地域の13歳女子・男子生徒は青灰色の学校服と同じ形の布鞄、41歳男性教師は灰色シャツと深緑ベスト。同じ人物の顔、年齢、髪、服、鞄を変えない。

倫理規約: 子どもを汚れ、裸足、涙だけで教育格差の象徴にしない。外部支援者を救世主にしない。女子だけを被害者、男子だけを自由な学習者にしない。欠席・中退を家庭の責任だけにせず、費用、交通、安全、学校設備、教師、障害、言語、紛争の複合要因を示す。digital学習は端末配布だけで成功にせず、教師、電力、接続、オフライン、保守、現地語、アクセシビリティを含める。
