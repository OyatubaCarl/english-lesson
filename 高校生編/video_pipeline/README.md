## 固定ルール

- `planning/adopted_songs_h001_h160.json` が動画制作側の統合マニフェスト。
- 非採用候補を、音源・映像・Sunoの識別印に使わない。
- 歌詞の意味が変わる箇所で画像を切り替え、画像枚数は曲の長さに応じて増減させる。
- 屋外は映画的な光と奥行き、屋内は現実的で自然な空間を基本とする。
- 画像内に読める文字を生成しない。字幕は動画工程で正確に重ねる。
- `REVIEW_STOPPED_AFTER_3` は採用を維持するが、字幕の誤語ハイライトを避け、QA注意を成果物に残す。

- 下段で英語化する語は、各レッスンの `high_lessons.json > vocabSentences.words` にある正本の新出語だけに限定する。
