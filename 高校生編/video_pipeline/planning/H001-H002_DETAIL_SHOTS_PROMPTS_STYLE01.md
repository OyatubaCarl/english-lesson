# H001・H002 描写寄り画追加プロンプト記録

## 共通指定

- Built-in Image Generationを使用。
- H15を基準とする画風01「光彩・劇場アニメ背景」。精密な2D線画、セル塗り人物、現実的で描き込まれた背景、群青の影と自然な暖色光。
- H001・H002の既存基準画を人物・衣装・場所・季節の参照にする。
- 歌詞が注意を向ける対象を、広景から寄り画／中景へ切り替えて明示する。
- 実動画の字幕帯に隠れないよう、重要物と顔は画面高55%より上を基本とする。下部45%は整理された背景。
- 16:9。画像内の文字、ロゴ、透かし、写真調、3DCG、油彩、絵本調は禁止。

## H001 追加8場面

### 2×2生成シートA

1. 静止した湖面と漂う薄霧への寄り。人物は遠景の小さなシルエットのみ。
2. 山の稜線から姿を現す朝日と、澄んだ空気へ扇状に広がる光線への寄り。
3. 岸辺を無言で見つめる17歳男子の横顔と上半身。視線の先に水際。
4. 少年の靴の近くを流れて湖へ注ぐ細い小川。水面の細かな光と小石への寄り。

### 2×2生成シートB

1. 遠い木々の枝で歌う数羽の小鳥。夜明けの逆光を受ける望遠寄り画。
2. 森の奥で枝葉がわずかに動き、鹿の輪郭がまだ判然としない「かすかな気配」。
3. 森の縁でじっと立つ一頭の鹿。鹿の顔と上半身を中心にし、少年は遠い背景。
4. 鹿が木々の奥へ身をひるがえし、後ろ姿と脚が幹の間に消えかける瞬間。

## H002 追加8場面

### 2×2生成シートA

1. 残雪の縁から落ちる水滴と、濡れた土に流れる雪解け水への接写。
2. 冬の灰色から若草色を取り戻す川沿いの野原と丘。春先の中景。
3. 湿った土を押し上げる小さな新芽と、柔らかな朝光へのマクロ寄り画。
4. 桜の下を川沿いに歩く17歳男子の胸上〜膝上の中景。落ち着く表情と水面。

### 2×2生成シートB

1. 川沿いを歩きながら表情が穏やかになる男子主人公の顔への寄り。
2. 同年代の女子の友人。昨年より少し大人びた姿、変わらない笑顔、輝く目を自然な胸上の寄りで示す。
3. 公園の子どもたちを見て、新しい希望と小さな喜びを感じる男子の表情。子どもたちは上部背景の柔らかなぼけ。
4. 春の夜、街灯に照らされた桜の若葉と新芽への寄り。世界が生きている余韻。

## 切り出し

各2×2生成シートは4つの16:9独立画像へ切り出し、最終動画には分割線・番号・文字を残さない。
